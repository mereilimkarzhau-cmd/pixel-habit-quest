# Pixel Habit Quest

Уютный трекер привычек в пастельно-розовой пиксельной эстетике. Выполняй ежедневные задачи, кормись опытом своего питомца, собирай редкие ачивки и соревнуйся с друзьями в челленджах.

Чистые **HTML + CSS + JavaScript**: без сборщиков, без зависимостей, без внешних запросов и ключей. Всё состояние хранится в `localStorage` браузера.

## Возможности

- **Питомец**: яйцо → малыш → подросток → король. Он растёт от опыта (XP) и меняет настроение: радуется, когда ты занимаешься привычками, и грустит, если пропускаешь дни.
- **Привычки**: добавляй, редактируй и удаляй; выбирай иконку и сложность (10 / 15 / 20 XP). Отмечай выполненное за день, смотри серию и последние 7 дней. За серию дают бонус к XP, за «идеальный день» (выполнены все привычки, от 2 шт.) — ещё +15 XP.
- **Ачивки**: 11 достижений четырёх редкостей (обычные, редкие, эпические, легендарные): «Первый шаг», «Серия из 7 дней», «Мастер привычек» и другие. У закрытых показан прогресс.
- **Друзья и челленджи**: лига недели и три совместных челленджа. Друзья — демо-персонажи с локальными данными, их прогресс считается в браузере, ничего не отправляется по сети.
- **Адаптивность**: интерфейс рассчитан на экраны от 360 px, есть поддержка `prefers-reduced-motion` и управление с клавиатуры.

## Структура проекта

```
.
├── index.html     # главный файл (в корне, как требует Vercel)
├── styles.css     # пастельно-розовая пиксельная тема
├── script.js      # трекер, XP, питомец, ачивки, челленджи, localStorage
├── assets/        # пиксельные SVG: питомец, ачивки, иконки привычек, друзья
└── README.md
```

Все пути в проекте относительные (`./styles.css`, `./script.js`, `./assets/...`), имена файлов — строчными буквами, поэтому он одинаково работает локально и на Linux-хостинге Vercel.

## Запуск локально

Достаточно открыть `index.html` в браузере двойным кликом. Если хочешь запустить через локальный сервер:

```bash
# Python
python3 -m http.server 8080

# или Node.js
npx serve .
```

После этого открой http://localhost:8080.

## Публикация на Vercel через GitHub

1. Создай репозиторий на GitHub и отправь в него проект:

   ```bash
   git init
   git add .
   git commit -m "Pixel Habit Quest"
   git branch -M main
   git remote add origin https://github.com/<твой-логин>/<репозиторий>.git
   git push -u origin main
   ```

2. Зайди на [vercel.com](https://vercel.com), нажми **Add New → Project** и выбери этот репозиторий.
3. В настройках оставь всё по умолчанию: **Framework Preset — Other**, поля Build Command и Output Directory пустые, Root Directory — корень репозитория (`index.html` лежит в корне).
4. Нажми **Deploy**. Каждый следующий `git push` в `main` будет автоматически обновлять сайт.

## Как устроена игра

| Что | Правило |
| --- | --- |
| Опыт за привычку | 10 / 15 / 20 XP по сложности + 2 XP за каждый день серии (максимум +10) |
| Уровни | для перехода с уровня L на L+1 нужно 40 + 20·(L−1) XP |
| Эволюция | яйцо (ур. 1–2), малыш (3–5), подросток (6–9), король (10+) |
| Счастье | +3 за отметку, +10 за идеальный день; итоги прошлых дней: +6 (всё выполнено), 0 (не меньше половины), −6 (меньше половины), −12 (ничего) |
| Отмена отметки | возвращает полученный XP, но ачивки и уже случившиеся эволюции остаются |
| Челленджи | считаются по отметкам со дня вступления; награда за повторную победу в 3 раза меньше |

## Сохранение и сброс

Данные лежат в `localStorage` под ключом `pixel-habit-quest:v1`. Внизу страницы есть кнопка «Сбросить весь прогресс». Если хранилище недоступно (например, в режиме инкогнито с запретом на данные), приложение продолжит работать, но прогресс не сохранится после перезагрузки.

## Пиксельный шрифт (по желанию)

Чтобы не делать внешних запросов, проект использует системные шрифты. Если хочется настоящий пиксельный шрифт, скачай подходящий файл с открытой лицензией (например, Pixelify Sans или Press Start 2P), положи его в `assets/fonts/`, подключи через `@font-face` в начале `styles.css` и подставь имя шрифта в переменную `--font-pixel`.

## Ассеты

Все спрайты (питомец в 4 стадиях и 3 настроениях, друзья, ачивки, иконки привычек) — оригинальные пиксельные рисунки 16×16 в формате SVG, увеличенные с `shape-rendering="crispEdges"`, поэтому остаются чёткими на любом экране.
